## 🚀 Последние проекты

### **1. Сайт для СМУ-37 (Django, PostgreSQL)**
*   **Описание:** Разработал полноценный веб-сайт для строительно-монтажного управления с 25+ летним опытом. Проект включал создание бэкенда на Django, проектирование моделей базы данных и интеграцию данных в HTML-макеты.
*   **Ключевые задачи:**
    *   Разработка архитектуры базы данных и моделей Django
    *   Интеграция записей БД с HTML-шаблонами
    *   Реализация функционала загрузки и хранения файлов
    *   Деплой проекта на хостинг и настройка production-окружения
*   **Особенности:** Уделено особое внимание работе с файлами, оптимизации запросов к БД и деталям реализации.

### **2. Бот для напоминаний с интеграцией нейросети (Aiogram, Google Calendar API)**
*   **Описание:** Продвинутый Telegram-бот для управления задачами с искусственным интеллектом, способный понимать естественную речь и голосовые сообщения.
*   **Ключевые функции:**
    *   Обработка нечетких текстовых сообщений и голосовых команд
    *   Интеграция с Google Calendar API для синхронизации напоминаний
    *   Умный парсинг и интерпретация временных промежутков
    *   Создание гибкой системы напоминаний
*   **Технологии:** Aiogram, интеграция с AI-сервисами, Google Calendar API, работа с аудио (STT).

### **3. Демонстрационный сервис на FastAPI (FastAPI, Docker, Celery)**
*   **Описание:** Производительное API-приложение для работы со звонками, демонстрирующее владение современным стеком технологий.
*   **Функциональность:**
    *   Создание и управление информацией о звонках
    *   Загрузка аудиозаписей звонков
    *   Фоновая транскрибация аудио через Celery
    *   REST API с автодокументацией
*   **Технологический стек:** FastAPI, SQLAlchemy, Pydantic, Celery, Docker, Docker-compose — полный цикл разработки современного микросервиса.
